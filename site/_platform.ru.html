Вторая половина

Без телефона ничего этого не выйдет

FLOP даёт личности повод существовать. Solana Mobile даёт ей безопасное место, чтобы родиться. Это приложение соединяет одно с другим, и на любом другом устройстве оно было бы хуже.

Seed Vault

Железо, которого нет больше ни у кого

Отдельный элемент безопасности с ключом кошелька, который не может прочитать ни одно приложение, ни это, ни какое-либо ещё. Он отвечает только подписью. Именно это делает выведенную из него личность одновременно воспроизводимой и неподделываемой.

Mobile Wallet Adapter

Любой кошелёк, а не один

Приложение никогда не лезет в Seed Vault само. Оно спрашивает через стандартный адаптер, поэтому отвечает тот кошелёк, которым вы уже пользуетесь, и вы видите, что именно подписываете, в нём самом, а не на нашем экране.

dApp Store

Распространяется там, где ему место

Сделано по требованиям магазина самой Solana Mobile, включая политику приватности, которая коротка, потому что коротка правда: ни аккаунта, ни аналитики, ни нашего сервера.

Seeker и Solana Mobile это товарные знаки Solana Mobile. Их логотип используется без изменений, из официального пресс-кита, чтобы сказать, для чего сделано приложение. Проект независимый, он не сделан Solana Mobile, ими не одобрен и не проверялся.
