FLOP Passport for Seeker

最終更新 2026年9月6日。このポリシーは Android アプリ dev.alexkosa.floppassport とこのウェブサイトを対象とします。

短い版。アカウントも、解析も、広告も、当方が運用するサーバーもありません。本アプリは、当方が手を届かせられるいかなる場所にも、あなたの個人データを収集・送信・保存しません。鍵はあなたの端末に留まります。

責任の所在

FLOP Passport for Seeker は、個人開発者 Alex Kosa による独立したオープンソースのプロジェクトです。FLOP Labs や Solana Mobile が作ったものではなく、承認も審査もされていません。連絡先：flop-passport@alexkosa.dev、X では @AlexKosa1、または公開リポジトリに issue を立ててください。

アプリが端末に保存するもの

  • あなたの Passport の鍵。暗号化された状態でのみ保存され、端末のハードウェア鍵ストアが保持する鍵で包まれます。その鍵はストアから読み出せません。
  • あなたの公開された身元、すなわち did:key とその指紋、そしてそれを導いた Solana ウォレットのアドレス。
  • 投稿のためにあなたが書いた一行、貼り戻した投稿のリンク、そして入力した場合は貢献のリンク。投稿のリンクはあなたのソーシャルアカウントを名指しするので、アプリが保持するもののうち最も身元が分かるものです。
  • 選んだ言語、起動音を有効にしているかどうか、ノートに最後に書き込まれた時刻、そしてどのリマインダーをすでに表示したか。

これらはすべて、端末上のアプリ専用領域に置かれます。本アプリでは Android の自動バックアップと端末間の引き継ぎを意図的に無効にしているので、いずれもクラウドのバックアップには複製されません。

端末から出ていくもの

  • technocore.chat へ。身元を公開するとき、また記録に署名するとき：あなたの公開 did:key、署名対象のテキスト、カウンター、そして署名。この情報は設計上公開されるものであり、それこそが公開された身元の意義です。後から誰でも読めます。
  • technocore.chat へ、あなたの公開された身元ノートの中に。公開した投稿のリンクを貼り戻した場合、そのリンクが入ります。リンクはあなたのソーシャルアカウントを名指しし、鍵から計算される恒久的な公開アドレスに置かれ、鍵とあなたの名前を人前で結びつけるのはこれです。貼るかどうかはあなたが決めますし、リンクなしでノートを書き直せば消えます。
  • 投稿を共有するときにあなたが選んだアプリへ（X など）：投稿の本文。アプリはそれを OS の共有シートに渡すだけで、自分から投稿することはありません。
  • あなたのウォレットアプリへ。Passport を作成するとき：署名すべき一文。ウォレットは端末上でそれを処理し、当方がネットワーク経由で何かを送ることはありません。
  • あなたが選んだファイルへ。鍵を書き出すとき。保存先はシステムのファイル選択画面で指定します。どこにもアップロードされません。
  • technocore.chat へ、あなたが何も押さなくても。アクティビティのタブを開くと、アプリはあなたのノートと記録を読み直し、ノートを書き直します。その書き直しこそが目的です。あのサービスは七日間だれも書き込まなかったものをすべて削除するので、アプリを開くこと自体が、あなたの身元を消させずにおく行為なのです。送られるのは、すでにそこで公開されているものと同じノートです。

開発者へは何も送られません。送る先となるバックエンドがそもそもありません。アプリが通信するのは、FLOP Labs が運用する technocore.chat と、あなた自身のウォレットアプリだけで、これが全部です。

アプリが決して求めず、決して触れないもの

  • Solana ウォレットの復元フレーズや秘密鍵。アプリはそれを見たことがなく、見ることもできません。
  • 氏名、メールアドレス、電話番号、その他アカウントの認証情報。
  • 連絡先、写真、ファイル、位置情報、カメラ、マイク。
  • 広告 ID。広告はなく、広告 SDK もありません。

解析と追跡

ありません。アプリには解析 SDK も、クラッシュ報告サービスも、第三者による追跡の類も入っていません。このサイトは Cookie を置かず、訪問を数えず、サーバー側のコードを持ちません。外に出る通信は二つだけです。一つは Google Fonts から取得するウェブフォント二種で、フォント配信元がそうであるように、先方にはあなたの IP アドレスが渡ります。もう一つは検証ツールを使ったときの technocore.chat への直接の読み取りで、これはあなたのブラウザから出て、こちらを通ることはありません。サイト自体は静的ファイルで、配信もリクエストの処理も Cloudflare が行います。私たちは自分のコードを動かしておらず、ログも保持していません。

権限

  • インターネット — 何かを公開したり署名したりするときに technocore.chat へ接続するため、そしてアクティビティのタブを開いたときに記録を読み直し、ノートを期限切れにさせないため。
  • バイブレーション — 手順が検証できたときの短い合図のため。
  • 生体認証 — 秘密鍵を表示する画面を守るため。
  • 通知 — 毎日のリマインダー、終えていないステップの知らせ、そしてノートが消える前の警告。
  • 起動時の実行 — 端末を再起動したあとに、上のリマインダーを設定し直すためだけのものです。起動時にそれ以外のことはしません。

ストレージ権限は要求しません。ファイルの保存はシステムの選択画面を使います。

データの削除

端末上で。設定 → 危険な操作 → Passport を削除、またはアプリをアンインストールします。どちらでも、暗号化された鍵、あなたの身元、設定が端末から完全に消えます。他のどこにも複製はなく、当方が代わりに削除するものもありません。

公開されたもの。Technocore に公開すると決めたものはすべて公開であり、私たちの手の届かないところにあります。こちらで保管しておらず、削除もできません。公開ルームの記録はルームが圧縮されるにつれてあのサービスが捨てていき、身元ノートは何も書き込まれないまま七日が過ぎると削除されます。つまり公開したものは、書き直さなければひとりでに消えます。technocore.chat 上の内容についての依頼は、運営元の FLOP Labs へお願いします。

子どもについて

本アプリは子どもに向けたものではなく、子どもを含め誰からもデータを収集しません。

変更について

本ポリシーが変更された場合、冒頭の日付も併せて変わり、以前の版は公開リポジトリの履歴に残るので、誰でも見比べられます。

あなたの権利

アクセス、訂正、可搬性、消去の権利は、他者が保持するあなたに関するデータをあなたが制御できるようにするためのものです。当方は一切保持していません。アクセスも書き出しも消去もするものがないのは、あなたに関する何もが当方に届かないからです。鍵はいつでもアプリから書き出せますし、アプリを削除すれば、それが保持していたものはすべて消えます。
